Project Documentation Phase Project Name: EduGenie – Google Gemini Powered Learning Assistant Purpose: EduGenie helps students understand topics more easily by giving simple explanations, quick summaries, and practice quizzes, all powered by the Google Gemini API. Problem Statement: Students often struggle to find quick, simple explanations for topics they don't understand, and few tools combine explanation, summary, and self-testing in one place. Solution: EduGenie lets a student type any topic and get: A simple explanation A short summary A multiple-choice quiz to test understanding Tech Stack: Frontend: React, TypeScript, Tailwind CSS AI Model: Google Gemini API Environment: Node.js How It Works: The student enters a topic or question. They choose Explain, Summarize, or Quiz. The app sends the request to the Gemini API. The response is displayed instantly on screen. Benefits: Saves study time Simplifies complex topics Encourages self-testing through quizzes Conclusion: EduGenie demonstrates how generative AI can be used to build a practical, accessible learning tool for students.
